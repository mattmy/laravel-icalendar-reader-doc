# Laravel iCalendar Reader documentation

English and Traditional Chinese documentation for
[`mattmy/laravel-icalendar-reader`](https://github.com/mattmy/laravel-icalendar-reader).

## Local development

```bash
npm install
npm run docs:dev
```

Node.js 24 or later is required.

## Production build

```bash
npm run docs:build
npm run docs:preview
```

GitHub Pages URL:

```text
https://mattmy.github.io/laravel-icalendar-reader-doc/
```
